# With Momo Official Website

Official website for **위드모모 (With Momo)**, prepared for GitHub Pages and `www.with-momo.com`.

## Files
- `index.html` — official homepage
- `privacy.html` — website privacy policy
- `styles.css` — responsive styles
- `favicon.svg` — favicon
- `CNAME` — custom domain configuration
- `.nojekyll` — serve static files as-is

## GitHub Pages
1. Make this repository public (if using GitHub Free).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. In your DNS provider, create a CNAME record for `www` pointing to `hmooko.github.io`.
6. In GitHub Pages settings, confirm the custom domain is `www.with-momo.com` and enable HTTPS when available.

## Google Play organization verification
Use `https://www.with-momo.com` as the organization website after the domain is live and ownership can be verified in Google Search Console.
